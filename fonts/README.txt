Seafood & Fresh Fish Market - Fonts Directory
===========================================
This template primary typography uses 'Plus Jakarta Sans' loaded via Google Fonts CDN in all HTML pages:
https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;500;600;700;800&display=swap

If you wish to host font files locally, place WOFF2 / WOFF files in this folder and reference them in assets/css/style.css.
