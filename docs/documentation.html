1. Overview & Tech Stack

Fish Market is a modern, responsive, ThemeForest-ready HTML5 template created for fresh seafood businesses, harbor markets, fishmongers, and online delivery startups.

HTML5 Semantic
Bootstrap 5.3.3
Vanilla ES6+ JS
Dark Mode & RTL

3. Customizing Colors & Fonts

All brand colors are organized as CSS custom properties in assets/css/style.css:

:root {
  --color-primary: #0284c7;        /* Sky Ocean Blue */
  --color-primary-dark: #0369a1;   /* Deep Blue */
  --color-secondary: #0f172a;      /* Deep Navy */
  --color-coral: #f97316;          /* Fresh Salmon Coral */
  --color-seafoam: #10b981;        /* Seaweed Fresh Green */
}

4. Adding / Editing Products

Edit the array in assets/js/products.js to add products instantly without altering HTML markup:

{
  id: 'prod-salmon',
  name: 'Norwegian Atlantic Salmon',
  category: 'fish',
  categoryLabel: 'Fresh Fish',
  price: 34.50,
  rating: 4.9,
  reviews: 128,
  badge: 'Fresh Catch',
  origin: 'Cold Fjords of Norway',
  image: 'https://images.unsplash.com/...',
  desc: 'Rich in heart-healthy Omega-3 fatty acids...',
  cuts: ['Whole Cleaned', 'Fillet', 'Steak Cut'],
  available: true
}

6. Dark Mode & RTL Support

The template comes with built-in theme persistence using localStorage. Calling window.toggleTheme() or window.toggleDirection() automatically switches modes, updates HTML attributes (data-theme="dark", dir="rtl"), and toggles button labels.

7. Form Validation & Toast Alerts

Interactive form validation runs via assets/js/validation.js. Trigger custom notifications anywhere in your scripts using: 

window.showToast('Your custom message here!', 'success'); // or 'error', 'info'
