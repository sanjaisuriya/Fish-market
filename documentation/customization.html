Customization & Color Variables

Easily customize the primary brand colors, typography, and product datasets.

Changing Brand Colors in assets/css/style.css

:root {
  --primary-color: #0f4c81;     /* Deep Ocean Blue */
  --secondary-color: #00a896;   /* Fresh Teal Accent */
  --accent-color: #ff6b6b;      /* Coral Badge */
  --bg-main: #f8fafc;           /* Light Theme Background */
}

Modifying Product & Market Datasets

Edit JSON files inside data/ folder: products.json, recipes.json, testimonials.json, and market-prices.json. The frontend scripts automatically adapt without needing code changes!
