Dark / Light Mode Toggle System

How dark theme state management & CSS overrides work.

How It Works

The assets/js/theme-toggle.js script toggles the data-theme="dark" attribute on the root <html> element and stores the choice in localStorage under key oceanfresh_theme.

Dark colors are defined in assets/css/dark-mode.css using CSS variable overrides.
