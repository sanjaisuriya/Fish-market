Installation & Local Server Setup

How to deploy or run the OceanFresh website template locally.

1. Local Web Server Setup

Because this template uses asynchronous fetch() calls to load mock product, recipe, and price JSON data from data/*.json, opening HTML files directly via file:// protocol in browser may trigger CORS restrictions. We recommend running a local web server:

# Option A: Using Python built-in server
python -m http.server 8000

# Option B: Using Node.js npx live-server
npx live-server

2. Web Hosting Deployment

Upload the contents of the seafood-fresh-fish-market/ directory directly to your web server (Apache, Nginx, Vercel, Netlify, or cPanel public_html).
